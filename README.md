
# Python Lab 4 - Cubic Numbers

## Description
This project uses Python and Matplotlib to create
graphs of cubic numbers for Chapter 15.

## Features
- Plots the first 5 cubic numbers.
- Plots the first 5000 cubic numbers.
- Saves both graphs as PNG images.

## Requirements
- Python 3
- Matplotlib

## How to Run
1. Install dependencies:
   python -m pip install -r requirements.txt

2. Run the program:
   python Lab15_colinlee-2.py

## Output Files
- cubes_5.png
- cubes_5000.png
